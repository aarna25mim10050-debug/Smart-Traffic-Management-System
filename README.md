# Smart Traffic Management System

## 1. Overview

A Smart Traffic Management System is a Python based application that looks at how busy roadsre controls traffic lights in a smart way. The system focuses on roads that have cars and makes sure that emergency vehicles can go through easily. This helps make traffic move better and stop traffic jams.

## 2. Features

- Input how many cars are on roads

- Create random traffic situations

- Check how busy the traffic is

- Say if the traffic is Low, Medium or High

- Pick the road with the most cars

- Change the green light time based on how busy the road is

- Make sure emergency vehicles get through first

- Make reports about the traffic

- Find the road with the most cars

## 3. Technologies / Tools Used

- Python 3

- Git

- GitHub

- Google Colab / Python IDE
